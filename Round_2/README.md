## 🚀 How to Open the Designs

1. 🌐 Visit [EasyEDA](https://easyeda.com).
2. 🖥️ Open EasyEDA Standard or Pro, as appropriate for the source file.
3. 📥 Navigate to **File → Open → EasyEDA Source…** and select the relevant `.json` file.
4. 🔎 Inspect the schematic, PCB layout, component footprints, and routing.
5. ✅ Run **Design → Check DRC** to review design-rule violations.

*Menu names may vary slightly depending on the EasyEDA version.*
