# 🏆 Round 1 – iTest Bangladesh PCB Design Contest 2026

## 📌 Overview

Round 1 of the **iTest Bangladesh PCB Design Contest 2026** consisted of three main PCB design problems and one bonus circuit challenge. The round focused on PCB design, component selection, schematic interpretation, and practical electronics implementation using EasyEDA.

- 🏆 **Contest:** iTest Bangladesh PCB Design Contest 2026
- 🔄 **Round:** Round 1
- 🧩 **Total Challenges:** 4 (3 Main Problems + 1 Bonus)
- ⏰ **Submission Deadline:** 11:59 AM, 6 October 2026
- 🛠️ **Design Software:** EasyEDA

## 📋 Design Challenges

| Problem | 🔧 Project / Design | 📝 Description | 📂 Project Folder |
|---|---|---|---|
| P1 | SparkFun Artemis Development Kit | PCB design based on the SparkFun Artemis development platform. | [📁 P1_Artemis_Dev_Kit](P1_Artemis_Dev_Kit/) |

## ⚙️ Design Workflow

The general workflow for these PCB design challenges includes:

1. 📖 **Requirement Analysis** — Reviewing the problem statements, schematics, and design specifications.
2. 🔍 **Component Selection** — Identifying appropriate electronic components and footprints.
3. 🔌 **Schematic Design** — Creating or verifying circuit connections.
4. 🖥️ **PCB Layout** — Arranging components and routing traces in EasyEDA.
5. ✅ **Design Verification** — Checking connectivity, clearances, component placement, and design-rule violations.
6. 📦 **Final Submission** — Preparing the required project files and manufacturing outputs.
