The following criteria were specified for the contest:

| Evaluation Category | Weight |
|---|:---:|
| 📝 Schematic Design | 15–20% |
| 🧩 Custom Library Creation | 5–10% |
| 🟩 PCB Layout Design | 25–30% |
| ✅ DRC Compliance | 15–20% |

⚠️ DRC errors may incur a penalty of **5 marks per logical error**, as specified in the contest rules.

## 📜 Contest Rules & Design Approach

- 🛠️ All PCB designs are created using **EasyEDA**, following the supplied schematics, design requirements, and component lists.
- 🚫 No pre-made complete designs are used; reference libraries are permitted under the contest rules.
- 📄 Project files are organized separately for easy access and review.
- 🗂️ Files follow the naming convention `name_uni.filetype`, where applicable.
- 📑 Layer PDFs and design reports are included for documentation and evaluation.

## 🚀 How to Open the Designs

1. 🌐 Visit [EasyEDA](https://easyeda.com).
2. 📥 Open the EasyEDA editor.
3. 🗃️ Select **File → Open → EasyEDA Source…** and import the relevant `.json` file.
4. 🔍 Review the schematic, PCB layout, footprints, and routing.
5. ✅ Run **Design → Check DRC** to inspect design-rule violations.

*Menu names may vary slightly between EasyEDA versions.*
